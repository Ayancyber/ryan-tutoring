# Ryan Tutoring Website

A modern, responsive single-page application for an English tutoring business. Built from scratch to practice React and Tailwind CSS.

## 🚀 Features
- Fully responsive design (Mobile & Desktop)
- Smooth scroll animations using Framer Motion
- Interactive mobile sidebar menu
- Integrated Cal.com booking system
- Custom SVG icons and graphics

## 🛠️ Tech Stack
- **React** (Vite)
- **Tailwind CSS v4**
- **Framer Motion** (Animations)

## 💻 How to Run Locally
1. Clone this repository: `git clone https://github.com/Ayancyber/ryan-tutoring.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
